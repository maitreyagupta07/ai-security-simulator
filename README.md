# Enterprise AI Security Architecture Lab

An interactive security simulation platform designed to demonstrate how organizations secure both Generative AI Systemsand Agentic AI Systemsthrough architecture design, security controls, monitoring, and threat detection.

## Overview

Traditional presentations often explain AI security concepts theoretically. This project takes a different approach by providing interactive simulations that allow users to explore architectures, apply controls, observe threats, and understand the impact of security decisions in real time.

The platform consists of two dedicated security journeys:

### 1. Generative AI Security Simulator

Explore how a basic enterprise chatbot evolves into a secure Generative AI system.

Topics Covered:

* Enterprise Knowledge Integration
* Retrieval-Augmented Generation (RAG) Pipelines
* Threat Surface Analysis
* Prompt Injection
* Data Leakage Risks
* Security Guardrails
* Attack Replay


### 2. Agentic AI Security Simulator

Explore risks of an unrestricted AI agent and steps to make it secure for an enterprise

Topics Covered:

* Secure Agentic AI Architecture
* Least Privilege
* Tool Access Control
* Human Approval
* Sandboxing
* Monitoring & Telemetry
* SIEM Detection Rules
* Threat Correlation
* Anomalous Agent Behaviour
* Attack Replay

---

## Key Features

### Interactive Security Learning

Rather than reading static content, users actively participate in securing AI systems.

### Architecture Visualization

Security concepts are presented through architecture journeys and interactive flows.

### Threat Simulation

Users can observe how attacks occur and how controls mitigate them.

### Security Control Implementation

Demonstrates practical security mechanisms such as:

* Guardrails
* Least Privilege
* Tool Restrictions
* Human Approval Workflows
* Sandboxing
* Monitoring

### SIEM-Based Detection

Shows how:

* Telemetry
* Logs
* Behaviour Analytics
* Threat Correlation

are used to detect threats that cannot be fully prevented.


## How to Use

1. Open the simulator.
2. Select either:

   * Generative AI Security
   * Agentic AI Security
3. Follow the guided architecture journey.
4. Explore threats, controls, and mitigations.
5. Replay demos of attacks and security protocols
6. Review attack simulations and security outcomes
7. Understand how enterprise security controls improve overall resilience.

---

## Project Goal

The objective of this project is to provide an intuitive understanding of AI security by transforming complex concepts into interactive experiences. The simulator demonstrates not only individual security controls, but also how they work together within a broader enterprise AI security program.
